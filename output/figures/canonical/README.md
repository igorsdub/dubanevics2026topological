# output/figures/canonical

Every figure rendered once, under its stable identifier. The source of every other figure directory.

## What
One PNG per figure and variant, named by its stable stem (for example `papkou2023_study_tree_persistence_metrics.png`, or a parameter-grammar stem such as `bootstrap__thr=reflected_fdr=by_q=0.05_…_style=annotated.png`). Titleless renders sit here; titled twins (figure title, subtitle, panel headings) sit in `titled/` with the same names.

Tracked in git: this README and the PNGs of the stems `config/manuscript.toml` names (an allow-list in `.gitignore`, regenerated by `scripts/dev/sync_figure_gitignore.py`; a test checks it). Titled twins, other renders and JSON sidecars stay local and are rebuilt by the render jobs.

## How it is generated
`build figures` renders each registered figure from saved products only, once with `titled = False` and once with `titled = True`. Titles and their texts are presentation settings in `config/figures.toml`.

## Command
`just figures` (on the cluster: `jobs/figures.sbatch`); one figure: `uv run python -m dubanevics2026topological.build figures --figure <id>`.

## Inputs
The stage checkpoints and datasets each figure's render record lists.

## Outputs
`<stem>.png`, `titled/<stem>.png` and a render record per file.

## Provenance
Render records key on input fingerprints and artefact hashes; a figure is re-rendered only when one of them changes.

## Caveats
Do not edit or rename files here by hand: the namer and the render records refer to these stems.

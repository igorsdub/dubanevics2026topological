# Changelog

One entry per merged pull request, newest first: `#number title (merge date)`. The earlier free-form detail is in git history (`git log -- CHANGELOG.md`).

- 1.0.2 (2026-11-26) Metadata release: the Zenodo DOIs of the code (concept DOI 10.5281/zenodo.24550751; version 1.0.1 is 10.5281/zenodo.24550752) and of the result files of the analysis run (10.5281/zenodo.24545428, in the layout of release 1.0.0) are recorded in `CITATION.cff` and the README; the wording of `just fetch-data` is corrected (no `data/processed/` deposit exists yet, so it stays unavailable). No code, number, figure or table changes.
- 1.0.1 (2026-11-26) Display release: only the text on figures and tables changes; the pipeline, the processed products and every number are unchanged. Figures and tables name the graphs Full, Papkou, Papkou + FDR, Topographer and Topographer + FDR (with the bootstrapped forms "Papkou + FDR, bootstrapped" and "Topographer + FDR, bootstrapped"), the thresholds Papkou threshold and Topographer threshold, and the branches KEM branch, TCL branch and All branches (`figures/labels.py`). The saved landscape-summary column names are product identity and keep their names; the exported summary tables show the new labels, mapped when the table is written. Supplementary figures are renumbered S1 to S14 (`config/manuscript.toml`); the numbered file slugs are renamed (Figure 3 `papkou_tree_metrics`, Figure 4 `papkou_tree_biology`, Figure 8's external file `topographer_fdr_tree_band_simplification.png`, Table S2 `topographer_corrections`, and the supplementary slugs such as `papkou_agreement`, `papkou_fdr_tree_combined`, `topographer_fdr_leaf_swarm`). `papkou_agreement` and `published_leaf_swarm_band` are in the default figure set; ten other former supplementary figures are opt-in. The peak uncertainty figure is a 2x2 whose panels are titled by the strict state label (Papkou, Topographer, Papkou + FDR, Topographer + FDR), without column headings. The S6 histogram is wider (385 px). The FDR scan (S2) draws the BY chart with the proportion axis clipped at 0.1. The bootstrap global stability figure (S6) is the histogram panel alone (the two-panel version is behind `show_diagram`). The band-quantile scan figure (S7) is the 2x2 again, Papkou and Topographer without FDR on the top row and with FDR below, titled with the strict state labels; the no-FDR panels are drawn when their bootstrap scans have been published to `data/processed/band_quantile_scan/<state>` and the figure is one row of the two FDR panels without them. Figures with FDR panels print the FDR level once ("FDR: BY, q = 0.05"), read from the analysis settings. Horton–Strahler orders use one orange palette. Figure 9: the three sweep headings share one left edge, baseline and top rule; the grey outside-span fill and its note are gone and the cells outside a population's fitness span are left blank (also in the Full and Papkou entropy figure S14 and the branch entropy view); it has no footer of its own, the annotated variant footer states the threshold and q. The tracked figures and tables of 1.0.1 were re-rendered from the archived results of the 1.0.0 analysis run (no recomputation), using the display code of this release ported to the code state that produced those results; a fresh `just all` reproduces the same numbers with new provenance records (the table JSON `source` fields and `table_identity_sha256` come from the archived run). Editing `build/figures.py` (the variant footer) changes the code label of several stage records; their results are unchanged. Supplementary S1 (`papkou_agreement`) is a 2x2 figure: fitness against standard error for Papkou et al. (2023) and BarSeqFit on top, the two agreement panels below, one shared logarithmic colour bar, the wild type marked in the BarSeqFit panel; the two top panels print only their genotype count (no Spearman line), the BarSeqFit count being the matched genotypes plus the wild-type row shown as the star; its file is `papkou2023_fitness_and_se_barseqfit_agreement`. Figure 1 exchanges the two peak colours; the Full and Papkou entropy figure S14 draws one shared "Entropy (bits)" colour bar at its right.
- Tables renumbered: the former main Tables 1 and 2 (Published-versus-Full landscape summary and candidate corrections) are now supplementary S1 and S2; the new main Table 1 is the four-graph descriptive statistics and main Table 2 the BY split tree versus its band-simplified tree. Both are built in `just figures`. New supplementary figure: positional amino-acid entropy of the Full and Papkou graphs against fitness threshold (`graph_codon_entropy`).
- The reported KEM/TCL common saddle setting (`reported_saddle_dna_sequence`) is now SCQ (`AGTTGCCAA`), not LCL (`CTCTGCTTG`); the codon-entropy stage, `manuscript_quantities` and the figures that read them (including `bootstrap_codon_entropy`) are rebuilt on the next run, because the `[codon_entropy]` settings are part of their fingerprints. The mechanism note states whether the computed saddle lies below or above the reported one.
- Agent guidance files (`AGENTS.md`, `CLAUDE.md`) are part of the public tree.
- 1.0.0 (2026-11-26) First public release, accompanying the manuscript "Topological characterization of combinatorial fitness landscapes using merge trees". Local-only pipeline: `data/processed/` is the single processed-data folder (`just all` writes it, `just figures` only renders from it, `just fetch-data` downloads it, `MANIFEST.tsv` checks it); the cluster workflow, the retained-archive pins, the tracked `data/reference/` mirrors and the draw-sliced bootstrap are removed; the band-quantile scan figure shows the two BY graphs; figure fonts fall back to Liberation Sans, then Helvetica
